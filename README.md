# CASE OMEGA
## Investigation of Cyber Crimes

Assignment 3 - Unit 3

Case Title: Investigating a Ransomware Attack on a Healthcare Network

### Objective
To simulate an end-to-end digital forensic investigation
of a ransomware attack on a fictional hospital network.

### Investigation Modules
1. First Responder Simulation
2. Evidence Collection and Chain of Custody
3. Malware Application Analysis
4. Data Acquisition and Timeline Creation
5. Final Investigation Report
